# 工作流效果评估

[English](evaluate-workflows.md) | 简体中文

用于判断一份方法与 Sheltie 的组合是否改善真实任务。开始前固定采用范围、比较条件、质量标准与预算，在对应 change package 保存协议和证据；不预设收益。

## 先固定比较对象

使用尚未解决的真实任务，写清使用者、目标、初始候选、完整方法、模型／宿主、独立质量标准、预算和停止条件。原生组与 Sheltie 组使用等价的目标、方法内容、质量和授权门槛；原生组也认真配置自己的阶段、审查与交付方式。

分别记录方法制作、首次输入和后续复用。首次使用由实际 actor 的使用历史决定，不由 sample 编号决定。换执行者、预先练习、先完成另一组、任务泄露和跨组学习都可能改变对照条件，需单列其影响。

组合试用可以发现摩擦，不能分离证明成果选择、撤销、导出或预检各自的独立收益。需要单独归因时，以新的等价任务和预注册条件测试一个增量，不重做已解决问题冒充学习前后的收益。

## 保存哪些事实

| 类别 | 至少记录 |
| --- | --- |
| 身份与输入 | sample／run／actor／arm、真实使用历史、模型／宿主／二进制、冻结任务与初始候选 |
| 活动 | 所有参与者的准备、配置、执行、核对、返工、接管、交付与接受活动及实际区间 |
| 等待和费用 | 墙钟、工具与模型等待、原始 usage、实际付费与来源；未知记 null／unknown |
| 结果 | 实际候选、patch、检查输出、最终成果、独立质量、流程外用户接受、未完成与停止原因 |
| 中断 | 自然或注入、原因、重开或换人事实、接续输入和重复工作 |

同一人的活动区间不能重叠重复计时。公共方法准备、每组配置维护、每次执行与实验测量分析开销分别归类。Attempt 时长含等待，不替代人工计时或模型费用。

## 质量与成本一起判断

固定质量标准后，由未参与求解的审阅者检查实际候选与最终交付。可用中性编号隐藏组别线索，但不能改代码、检查内容或必要来源；无法盲审时明确记录偏差。日常 review、流程成功、gate 与最终用户接受分开。

未接受、失败或交付阻断的任务也计入已发生成本，不只统计成功样本。报告每组原始样本、准备与维护成本、每次成本、最终质量和缺项；不知道成本时不计算节省比例。阈值是本次采用的判据，不是普遍产品承诺。

质量下降、预算到顶、输入漂移或必要环境缺失时停止对应运行，保留实际结果，不放宽标准取得成功。结束后可以选择缩小方法、改善说明、暂不增加机制或停止方向。
