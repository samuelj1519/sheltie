# D-046：首个对外支持基线

[English](../../../en/explanation/decisions/D-046-first-public-baseline.md) | 简体中文

Status: `accepted`
采用日期：2026-10-06
关联 change：[C013](../../../../specs/changes/active/C013-first-public-baseline/README.md)

项目所有者确认，刚重建的仓库尚无外部用户，并授权撤回重新上传的 v0.1.0／v0.2.0 发布。当前实现经过候选验证和实际发布附件验证后，以 v0.3.0 作为首个对外支持基线。保留当前版本编号，不将已经发布过的名称重新分配给不同内容。此次调整改变发布和支持策略，不改写历史验证结论。

保留当前 schema 4、cli-result/v4、workbook-digest/v2，以及独立编号的 Workbook 版本。不添加旧格式解析、迁移、双格式或旧命令别名。当前数据校验、拒绝时保护原始字节、请求重放和崩溃恢复仍为必要要求。重置格式编号或删除拒绝测试会增加风险，且没有实际消费者需求。

已撤回版本的记录保留固定源码提交、验收闭包提交、原始校验和、限制及原始结论。记录必须明确撤回依据；删除 Tag 后仍须能验证这些固定提交。若 Tag 仍存在，其身份必须与记录一致；仍在发布的版本继续要求精确匹配的 Tag。撤回发布不重写 Git 历史，也不授权删除用户数据。[D-043](D-043-development-target-authority.md) 继续区分开发目标、候选、发布和验收。
