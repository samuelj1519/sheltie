# 历史档案

[English](README.md) | 简体中文

本目录供维护者追溯已关闭变更的范围、理由、验证限制和原始记录。学习与使用当前产品从[文档首页](../README.zh-CN.md)开始；当前行为依据见[规格](../../specs/README.zh-CN.md)。

- [已关闭变更](changes/README.zh-CN.md)：按 change 编号查摘要和固定 Git 快照。
- [发布记录](../reference/releases/README.zh-CN.md)：查正式版本、实物和发布范围。
- [设计决定](../explanation/decisions/README.zh-CN.md)：按主题理解设计理由及其当前适用范围。

历史摘要保留原结果，不替代当前候选验证。完整计划、验证和审查从记录指定的 Git 快照读取，方法见[历史查阅指南](../how-to/maintain-docs.zh-CN.md#查阅历史原件)。

[Git 提交信息迁移映射](git-message-migration.zh-CN.md)用于对应原提交与英文本地提交身份；历史文件树及远端发布证据保持原样。
