# 历史档案

本目录供维护者追溯已关闭变更的范围、理由、验证限制和原始记录。学习与使用当前产品从[文档首页](../README.md)开始；当前行为依据见[规格](../../specs/README.md)。

- [已关闭变更](changes/README.md)：按 change 编号查摘要和固定 Git 快照。
- [发布记录](../reference/releases/README.md)：查正式版本、实物和发布范围。
- [设计决定](../explanation/decisions/README.md)：按主题理解设计理由及其当前适用范围。

历史摘要保留原结果，不替代当前候选验证。完整计划、验证和审查从记录指定的 Git 快照读取，方法见[历史查阅指南](../how-to/maintain-docs.md#查阅历史原件)。
