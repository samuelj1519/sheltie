# Historical archive

English | [简体中文](../../zh-CN/history/README.md)

Maintainers use this archive to trace scope, reasons, validation limits, and original records of closed changes. Start at the [documentation home](../README.md) for current learning/use; [specifications](../../../specs/README.md) govern current behavior.

- [Closed changes](changes/README.md): summaries and fixed Git snapshots by change ID.
- [Release records](../reference/releases/README.md): official versions, artifacts, and release scope.
- [Architecture decisions](../explanation/decisions/README.md): design reasons and current applicability by topic.

Summaries retain original outcomes without replacing current-candidate validation. Read complete plans, validation, and reviews from the specified Git snapshots using the [historical lookup guide](../how-to/maintain-docs.md#read-original-historical-records).
