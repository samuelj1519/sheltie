## 单任务测试命令

在项目根运行，按 Task 归属选择实际测试；不要求测试名带任务编号。项目已有 Task 脚本时：

```bash
scripts/task.sh <Task>
```

没有 Task 脚本时，填写按任务卡完整测试名单生成的命令（如 nextest 的精确名称筛选）。零个测试匹配时命令必须失败；记录实际测试数，与任务卡逐项核对。
