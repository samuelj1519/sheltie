# 取得可编辑的最终成果副本

本指南描述已采用C006目标。当前实现和可用入口以 [C006 plan](../changes/active/C006-result-delivery/plan.md) 为准；正式接线后从当前源码临时构建，工具尚未发布/安装。先用同一显式管理根查询 work result；仅需要引用时使用原结果入口。

工具要求可信sheltie绝对路径、真实无链接绝对管理根、完整WorkId及已存在真实目标父目录。它核全体选定最终成果后新建独立副本，不覆盖已有目录；路径和失败处置取实际响应。完整raw/manifest/限额与退出状态见 [协议§8](../contracts/protocol.md#8-最终-artifact-原字节与外围导出)。实际构建命令、操作和残留核查在C006冻结runbook中给出；真实用途与人工成本不由工程测试代替。
