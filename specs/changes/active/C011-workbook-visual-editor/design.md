# 作者工具设计

## 小接口与可信结构判断

浏览器的文件map是Workbook草稿，不是Work状态。原字节在界面用Map保存；传输用逐项二元数组 `[[relative_path, base64], ...]`，不先用JSON对象或ZIP解包覆盖同名entry。UI解析manifest/Flow仅供表单和画布，完整原始对象和未编辑文件仍是来源，不从workbook show的有限投影重建定义。节点拖动位置留在localStorage，语义字段只写入当前合同允许项。

服务端有两个草稿操作：check和export。HTTP请求体流式累计最多24MiB，超限停止，不先拼接全部字符串；解码前逐entry核类型/数量、编码长度和严格base64，实际累计文件至多16MiB。相对路径不得是绝对路径/盘符、含反斜杠/NUL/冒号/空段/`.`/`..`；重复、ASCII大小写/NFC别名、目录拼写别名和文件/目录前缀冲突整体拒绝，不规范化后丢弃。每个路径UTF-8至多4096字节。全部前检通过才在0700自有新临时目录独占创建文件；物化后实际文件集合/字节须与输入逐项相同，否则拒绝，不能用文件系统别名洗掉路径差异。

只用固定可信sheltie的直接argv和该次新Home调用workbook add。单次CLI期限30秒、stdout/stderr各最多1MiB；超时、输出超限或请求断开先停止该次直接child，TERM后至多1秒升KILL，再等待退出/流关闭后才清理本次根。不能确认退出时保持失败，保留根及准确残留原因，不删除它或父目录，不称整棵进程树停止。引擎返回的结构判定才授校验结果；非零/不完整JSON/超时保持失败。export重新校验它收到的确切文件集合，成功后生成完整ZIP，不消费上次UI的绿色标记。不读/写正式Home或打开的作者目录。

HTTP只监听127.0.0.1，Host必须是实际127.0.0.1:port，变更Origin必须精确等于该http来源，缺失/null/其他来源均拒绝；变更请求使用启动会话随机token，缺失/错误token拒绝。不提供任意路径读取、shell或任意binary调用。静态资源路由是固定白名单/依赖目录，拒绝路径逃逸。它不声称同一OS账户下的人类认证或进程树隔离。

说明、标题、ID、路径和错误信息都作为文本显示，不把导入内容插成可执行HTML或脚本。实际渲染拒绝/转义场景必须覆盖带HTML标记的说明文本。

## 文件与编辑保真

目录选择先按File清单累计大小/数量、核全部相对路径，再读取内容；第一版16MiB/1024文件，文件读取后的实际集合/大小另核。不支持对象或超限立即报告，不丢文件继续。第一版没有ZIP导入，下载的ZIP先由用户解压再选择目录；因此不增加一个解压输入安全面。Markdown说明保留原关联文件；未编辑的Flow/TOML/二进制resources保持原bytes。

编辑过的TOML可以重排格式，但保留完整原始对象，包括未知字段；只更新实际编辑字段，不用表单允许字段重建整个对象。未知字段导入后修改另一个合法字段，检查仍须拒绝。无法解析或界面不能表示的文档保持原字节并明确拒绝相应编辑，不替换成模板或静默省略。高级合法声明在相同操作后保持。引用删除后的非法草稿由检查定位，不猜新的入口或来源。

完整格式保持workbook/v1与flow/v1。表单基础检查只改善反馈，不代引擎最终校验。TOML/ZIP使用公开库而非自写parser，接口核对见 [smol-toml](https://github.com/squirrelchat/smol-toml) 和 [fflate ZIP](https://github.com/101arrowz/fflate/blob/master/docs/functions/zipSync.md)。源和依赖实际版本在准备产物中固定，不把网页最新文档当已安装事实。

## 界面

遵循用户的节点画布方向。基色 #162131，画布 #111a27，面板 #202d40，文字 #e5edf6，主操作 #67a9e8，门槛/人工标记 #d7aa5e。中文正文系统字体，标题18px、表单14px、ID/绑定12px等宽。图占主要空间；左侧方法/Flow导航，右侧属性；检查错误位于底部可展开列表。选中节点高亮，边标签使用真实kind；不放装饰性的指标卡或无关运行面板。

键盘焦点清晰，可用表单/节点列表选择节点。窄屏属性面板折叠，尊重减少动画设置。空画布引导增加节点；错误说明具体文件/字段和下一步。
