# 正式run关闭重开卡模板

状态：尚无正式run，未发生关闭重开。本卡仅在正式准入、实际到达冻结阶段后填写。两组持久材料与帮助范围必须事前等价，不能带另一组答案或额外聊天提示。

```text
协议/正式run/arm：待填
实际任务/初始副本/授权范围/质量标准引用：待填
本组方法及持久材料路径/SHA：待填
当前仓库/候选/已有变更/检查/草稿身份：待填
模型/host/权限与原生持久记录规则：待填
Sheltie组：engine绝对路径/SHA；显式Home；Work ID；旧Attempt/revision（Native组不填）
旧会话标识、执行者实际停止证据、保存/关闭时间：待填
新会话标识、打开时间：操作者实际填写
接续的查找/核对/重做/帮助活动记录：实际追加，不估算
```

新会话先读取本组协议允许的自然材料。Sheltie组再只读 `work status`，核Work/候选、pending标志、resume任务书/冻结输入/草稿和当前next；仍running就继续原Attempt。Native组按冻结的持久阶段记录核材料。不根据旧响应next推进。

旧执行者未停止、候选/输入不符、草稿缺失、权限或状态不明就停止并保存原因。真实新会话没有发生则保持not_run。同一会话“继续”、新worker替换或把历史聊天重贴给新会话都不能补原宿主重开证据。
