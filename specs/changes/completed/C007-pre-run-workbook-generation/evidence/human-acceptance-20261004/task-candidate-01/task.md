# 候选任务1：本地网页 Workbook 编辑器

状态：需求整理，未冻结、未正式准入。用户原始需求见 [user-request.json](user-request.json)。这是待确认的完整验收草案，不是已采用产品规格或已开始的实验。其余两个真实任务、预算、参与者/history、环境和正式顺序仍未补齐。

## 用户目标

提供简单易用的可视化界面，创建和编辑Workbook；由网页承载，采用类似ComfyUI的节点画布。默认理解为当前Sheltie仓库中的本地作者工具，编辑可变源码目录，不修改已登记版本或Work冻结副本。

## 第一版拟定范围

1. 在本机浏览器打开编辑器。中文界面采用左侧Workbook/Flow导航、中间节点画布、右侧选中对象属性；主要动作为“新建”“打开”“检查”“保存”。
2. 新建一个Workbook，填写名称、ID和版本，建立默认Flow并选择入口节点。能够打开现有Workbook，切换其已有Flow；不能丢掉未编辑Flow或资源文件。
3. 增加、拖动、编辑和删除节点；添加/删除流程连线，选择main/back/branch/re_review。画布可平移、缩放。连线表示显式流程边，输入来源单独设置，不从图形连线擅自推断输入绑定。
4. 编辑节点名称、执行者、说明书、输入和输出。门槛、档位、访问/重试上限、required/result等设置放在折叠区域；打开后未修改的有效声明须保留。已有instruction.file的实际文本可编辑，并保留其文件关联；资源文件不得因界面未展示而丢失。
5. “检查”给出可定位的格式/结构错误；“保存”产生可被当前Sheltie装入的完整Workbook。校验以既有合同和解析/编译规则为准，不另造一套与引擎不同的业务语义。

默认交付形式为独立本地网页工具，保存到操作者明确选定的作者目录；具体打开/保存机制在实施前核可行性并冻结。若浏览器或本地工具不能安全完成该方式，应在正式准入前调整验收，而不是运行中临时改成另一种交付。画布位置不写入workbook/v1或flow/v1未声明字段，也不成为引擎事实。

## 拟定验收

| 使用场景 | 必须行为 | 拒绝或保真要求 |
| --- | --- | --- |
| 从零创建两步方法 | 增加2节点、连线、指定入口、填写说明和输入/输出，检查后保存并成功装入 | 新增节点未连通、重复ID或不存在入口时定位错误，不能声称合格 |
| 编辑已有code-change | 打开样例副本，修改某节点标题和说明，保存/重开后仍显示修改 | 原返工边、可选输入、终点成果选择保持；不改仓库样例原件 |
| 打开较完整方法 | 打开spec-dev副本，能看全部节点/边和切换Flow；未编辑内容可保真保存 | 不丢gate/tier/requires/result/资源/其他Flow；不能悄悄截断图 |
| 删除有引用的节点或输出 | 提示受影响的连线/输入；删除后重新检查 | 不自动猜新入口或新输入来源，不以静默修复制造合法图 |
| 非法路径/引用/声明 | 当前解析/编译合同拒绝，界面指出位置 | 不写根外路径；未知字段、缺说明/资源、非终点result不得当成功 |
| 保存与实际消费 | 保存后重新打开，核心语义相同；临时Home实际add/show/verify可核 | 源变化或目标不明确时停止，不覆盖引擎管理副本或其他对象 |
| 首次用户使用 | 操作者能实际完成新建和修改，记录帮助与卡点 | 截图、自述或测试成功不代真人易用性接受 |

按 [Workbook合同](../../../../../../contracts/workbook.md)核所有已涉及字段；样例/真实目录只在独立副本验证。输出格式保持workbook/v1和flow/v1，既有引擎状态/协议不因编辑器变化。

运行、门槛批准、agent派发、Work监控、云端协作、账户、插件系统和模板市场不纳入第一版。“类似ComfyUI”指画布交互，不要求复制它的执行系统或视觉细节。
