## 第一版拟定行为

1. 交付本机可以打开的桌面应用窗口。用户能选择工作区、新建会话、发送需求、看到流式回复与工具活动、停止当前任务，并重新打开已有会话。
2. 使用dsh现有模型配置、会话和交互能力；桌面窗口承载已有可用界面。具体承载方式和桌面框架在正式准备中核可行性后冻结，不预先把某个框架安装为条件。
3. 可连接本机已运行的dsh，或由客户端明确启动自己的本地后端。启动/停止/重试给出清楚状态和错误；区分客户端拥有的进程与外部既有进程。不能退出应用时停止别人的dsh或删除会话记录。
4. 权限询问和真人批准沿dsh的真实接口处理。连接中断、后端崩溃、模型错误和用户取消都有明确反馈；不能把窗口打开或HTTP成功记为agent任务成功。
5. 跨平台是实现与构建组织目标：共享交互和应用主体，实际平台差异显式处理。本轮只交本机aarch64 macOS实际构建/启动/关闭重开和模型使用证据；Windows/Linux代码或配置存在不算该平台可用性通过。

默认功能只覆盖日常会话。复杂窗口管理、插件市场、云账户、自动更新、商业签名/公证和多平台实机验收不纳入本次第一版；后续有明确需要再采用。

## 拟定验收与停止

| 场景 | 必须观察 | 拒绝/边界 |
| --- | --- | --- |
| 打开Mac应用 | 真实应用窗口显示后端连接状态，能进入工作区与会话 | 只有浏览器页面/截图或开发服务器成功不代应用实物 |
| 真实DeepSeek会话 | 本机已配置可用模型后，发送真实请求，流式回复和工具活动可核 | 无凭据或真实API失败保持未执行/失败，不用mock授真实模型结论 |
| 多轮和取消 | 同一会话继续一轮；实际长任务可停止，停止后可以开始新的交互 | 不借取消偷偷启动新会话或声称整个宿主进程树已停止 |
| 关闭重开 | 真实关闭窗口/应用并新开，已有会话能按持久事实继续 | 不把同窗口继续或内存缓存当重开恢复 |
| 后端启动与连接失败 | 路径错误、端口占用、后端退出时给具体诊断和可用重试动作 | 不接管未知服务、重试到绿隐藏失败或改用户全局配置 |
| 进程归属 | 应用自启动的后端按冻结生命周期处理；外部已运行服务保持 | 不用宽泛进程名kill，不删除未知残留 |
| 本机交付 | 实际aarch64应用构建产物、版本/摘要、运行和使用步骤对应同一候选 | 其他平台原生验收仍not_run；本轮不自动发布/安装到全局位置 |

实际实现若改变上游dsh模块，遵守其AGENTS和对应目录规则；非局部产品改动的Agent Note、相关unit/keyless snapshot/built smoke与必要真实API验证在准入前列入命令。不默认重跑完整dsh套件，证据只覆盖执行的消费者。
