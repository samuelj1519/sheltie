# 节点资料属性整理

用户当前反馈：输入/输出为过长纵向列表，已使用资料在选择候选中没有勾选，难以浏览与操作。继续现有深灰蓝画布视觉，密度集中在侧面资料区，不加框架或布局库。

节点顶部保留标题/执行者等基本内容；资料区采用「输入 N / 输出 N」页签，说明折叠到资料区之后。列表默认仅一行名称和一行来源或文件摘要，按来源分组，支持名称/来源搜索；一次只展开一项的名称/来源/文件名编辑，精确配置继续折叠。列表与页签切换是视图，不提交默认值，不排序存储数组，不清除未知声明或integer/float差异。外部内容继续同一选择或输入资料框，不加路径或URL专门字段。

已有状态由当前node.inputs精确from匹配派生。候选显示已勾选及本步骤使用的名字，同一from多个别名均保持；已有候选为已用状态，不能误作为新的staged加入。已有勾选设为只读并提示「已使用；移除请在已选列表操作」，各行明确移除；未用候选仍可多选添加。原非法/缺失来源不洗白，新选择仍按原限制；重复候选、改名、移除一个别名、移除最后别名、新增、切节点、切Flow后状态必须以真实当前声明刷新。显示不能复制result/max_bytes或改变required省略/false/true。COW修改引用位置、删除输入不删除原资源等边界保持。

关键独立预期：spec-dev plan12输入/2输出，collapsed输入无需12套form；已有spec.spec、plan-review.reviewed-plan（名previous_plan）等候选勾选，而新输入候选不勾；多个别名同来源显示使用状态，移除一行其他别名保持，最后移除才解除已有勾选。输出列表只输出计数/摘要，展开编辑后保存真实CLI通过。切换/搜索/分组/折叠导出27文件逐byte原样。实际宽/窄窗口滚动可达，说明和高级声明可编辑，图片不代实际鼠标与原始ZIP。全部验证与finding留本目录，整体human接受仍false，旧时间窗失败原件不重写。
