# C011复杂方法可用性修订

目标读者不熟悉Flow合同。保持现有深灰蓝作者工具，只改善看清流程、选准连线、填写资料这三个动作。不开新框架、不修改引擎或Workbook格式。

## 布局与连线

默认位置依据当前图的主流程生成确定层次；遇循环不重复展开，旁支放侧列，孤立或非法节点也可见。这是排版，不是Flow合法性判断。已有拖动位置保留；“整理布局”显式重新排版并适应画布。适应画布包含外侧边线通道。主流程方向直观，返回方向用外侧通道；线型与中文类型区分继续、返工、分支、重新检查。手动移动后连线仍关联实际节点边界。

几何算法是生产调用的纯函数，生成实际路径、可点击标签与端点；往返线区分，不要求任意密图零交叉，不改变图。选中节点突出邻接边，选中线突出两端；完整图仍可访问。

## 选边

每条实际edge有自己的命中区域、中文可点击标签，并提供简短连线列表给密图选择。事件绑定实际edge对象，指针与重绘不得串到节点或另一边。右侧醒目显示“从〔节点标题〕到〔节点标题〕”，起点/终点/类型与高亮都是同一实际edge；未知kind不替换。浏览器必须以鼠标真实命中路径、标签、列表证明，不用键盘独自代替鼠标验收。

## 输入与输出

输入解释“这一步要读取什么”，常用显示本步骤资料名称和来源。选择任务开始时提供、另一步的输出、方法中的参考文件、运行统计、自定义来源；选实际步骤及声明输出或参考文件，生成既有start.<key>、<node>.<output>、resource.<path>、engine.stats。未知/非法原值落自定义并保留原文；无可选输出/文件显示空状态，不猜来源，未操作不写回。

输出解释“这一步要交出什么”，常用只显示名称和文件名/相对路径。“必须提供”“作为最终成果”“大小上限”放每项高级设置，保留省略/true/false三个声明状态；准确保留字节不丢精度。渲染不写默认，不加input/edge，不改变源输出，不洗白未知字段；公开CLI最终判断。

主表单不用name/from/required/result等字段作标题，精确语法在高级或原文。执行方式显示“由agent完成／由人完成”，其他已采用高级配置保留。
