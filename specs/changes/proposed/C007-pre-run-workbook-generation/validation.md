# C007 验证：先固定问题，再比较模板

Candidate: `not_run`
状态：`proposed`；所有 pilot、正式样本、盲审、安装核对均为 `not_run`。基线 `17a1647758ceea5ebf637610ab2cdf91589c5218`。

## 1. 样本与阶段

T01 选择两个首批目标里的真实 pilot：一个小代码变更、一个需独立审查的文稿任务。T02 每项各跑 A/B 一次，产生第一次使用结果。pilot 用来发现模板和说明缺口，不进入正式统计。

M1 通过后，T03 预注册六项正式任务：至少两项代码变更、两项文稿/技术说明，以及两项从真实近期需求选择的任务；覆盖简单执行和确需一次返工的目标。任务来自真实需求，由强模型在看正式生成结果之前固定交付标准、不可省略检查、重大/阻断缺陷的定义。不得为了模板适配删掉真实要求。

每项两组使用同一目标、标准、模型版本/参数、可用 CLI、现行规格与等价初始上下文；A 可用现有 examples，B 另可用固定模板。顺序按样本交错 A/B、B/A，独立会话，不让第二组读取第一组产物或盲审结论。正式执行前同一个初级执行者完成一项不计时练习。无法控制的模型/人因素在报告列明。

## 2. 计时与成本

每个样本记录：读需求、修说明、修格式、解释检查结果、人工确认的活动分钟；等待模型和命令的墙钟时间另列。记录简单模型生成调用、强模型模板设计与盲审调用、token/费用（不可取时写未知），以及用户必须补充多少次标准。

预注册的主要比较是配对样本的人工活动时间和两组中位数；不把等待时间称为人工负担，不丢弃失败样本。B 组不适配按失败记录真实停止时间，并影响覆盖门槛；不得将它从六项中删去。没有可比时间时结论不足，不推算百分比。

## 3. 独立盲审

盲审者为没有参与模板、目标 oracle、生成物或脚本实施的强模型。给产物随机编号并隐藏组别、模型与计时结果；既定标准对两组相同。能够从模板特征推测组别的局限在报告注明。

| 维度 | 核对内容 | 阻断例 |
| --- | --- | --- |
| 需求覆盖 | 所有交付对象和必需标准出现 | 删除必需鉴权/数据保存要求或缺最终文稿 |
| 工作方法 | 输入输出可定位，步骤可执行 | 说明要求读取不存在文件，产物无明确位置 |
| 检查与审查 | 标准由任务输入给定，检查可执行，审查独立 | 生成者自己宣称成功，省必需检查或自审 |
| 人工决定 | 必需门槛保留，不新增无理由的人审 | 可绕过必需批准，普通返工强制找人 |
| 返工与停止 | 拒绝结果有可走的回环和明确上限 | 无限回环、失败后仍直接结束 |
| 结果取得 | 当前格式能明确产出并找到所需成果 | 仅结束状态，不知道交付哪份文件 |
| 简洁与适配 | 没有多余节点/重复判断；不适配诚实报告 | 为填模板删除要求或加入无依据的制度 |

图合法不代替以上盲审；盲审通过不代替实际运行验证。本实验评估 authoring 和预运行可执行性，不宣称真实任务交付质量已由产品保证。

## 5. 采用判定与后续条件

六项中至少五项适配、人工活动时间中位数降低至少 20%、模板组零阻断且重大缺陷不增加，才能支持继续模板方向。六项不足以证明普遍效果；报告保留全部样本，说明强模型前置成本与复用假设，不虚构确定收益。

未达标时分别记录：固定图不适配、说明生成不正确、缺示例/文档、确认成本高、计时不可比。至少两项真实首批任务确因固定图结构不足才考虑自由图候选；不因语法错误或一个特殊任务直接扩展 checker。
