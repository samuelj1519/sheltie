# C007：用固定模板减少 Workbook 编写负担

状态：`proposed`
目标版本：`不进入产品 release`（实验结论决定后续是否提出产品化）
兼容性：不改产品代码、Workbook/Flow 格式、安装入口或宿主配置
基线：`17a1647758ceea5ebf637610ab2cdf91589c5218`
Owner：`待采用实验时指定`
权威性：候选实验方案；任务均为 `todo`，实验与实施里程碑均为 `not_run`；完整方案审查见 review

## 产品目标

第一次使用 Sheltie 的人应能为真实任务取得可运行的方法，而不先学习整张图、输入输出与返工边的全部细节。先验证可复用的固定 Workbook 图加任务说明/验收输入是否足以降低编写负担，再决定是否需要更自由的生成能力。

本方案是低成本 authoring 实验。强模型先制作少量固定模板、任务 fixture、独立质量 oracle 与操作脚本，简单模型按既定模板填写说明与任务输入；每个里程碑由另一强模型审查。首次使用结果在 T02 出现，不先实现完整工具。

## 范围

- 对照现有语法与例子直接编写/agent 辅助编写，测试固定模板填充的效果。
- 固定模板的图、门槛、次数上限与结果选择由强模型预先审定；生成者仅填写允许的任务文本与输入，不能放宽标准。
- 草稿、样本与证据留在本 package `experiments/` 或专用临时目录；现有 `workbook add/show/verify` 在隔离 Home 中验证。
- 不新增 Rust checker、crate、约束映射格式、锁定文件、签发机制或新命令。不做运行中展开。

## 成功判据

正式实验前在 T03 冻结两组的输入、模型、提示、计时、盲审标准与停止规则。以下是本实验的产品采用门槛，不是已有事实：

1. 六项预先选定真实任务中至少五项能由固定模板表达；不适配任务如实记录，不强行改图。
2. 模板组人工活动时间的中位数至少比直接编写组降低 20%；模型耗时、token 与强模型制作模板的前置成本另列，不用人工时间隐藏成本。
3. 模板组没有减少任务必需检查、审查、门槛或返工机会；盲审无阻断质量缺陷，不比对照组增加重大缺陷。
4. 全部被接受的草稿可用现有引擎校验，用户看得到图/说明/标准与差异；临时检查不会登记到正式管理根。
5. 本次实验结论只决定继续、缩小或停止模板探索；不宣称用户普遍收益，也不自动采用自由图检查器。

## 采用条件与依赖

人采用的是这份实验 plan，不是产品新行为。C002 的 Workbook 冻结/摘要/安装可靠性已经是既有基础，实验沿用现有接口，不重复建立摘要算法。实验可以基于当前已发布版本开展，不等待 C004–C006 或 C008；若使用 C004 新结果字段，必须固定实际实现版本并明确组间条件一致，不能用提案字段假装可运行。

正式管理根安装只发生在用户明确确认草稿后。未获安装确认时可完成临时校验、盲审和实验结论，不把正式安装视为实验必需步骤。
