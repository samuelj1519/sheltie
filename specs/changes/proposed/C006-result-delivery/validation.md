# C006 验证：副本价值与写入正确性

Candidate: `not_run`
状态：`proposed`；以下是预定验证，不是已执行结果。基线 `17a1647758ceea5ebf637610ab2cdf91589c5218`。

## 1. 副本需求探针

T01 在 C004 已验收的真实任务上选择一份需要可编辑文件副本的结果。先记录用户仅用 `work result` 是否已经满足目的；只有确实需要副本，才继续导出探针。用户不需要副本时记录「不采用当前导出范围」，不编造传送需求。

T08 用同一结果比较手工按明确 ArtifactRef 复制与导出器复制，记录人工分钟、重复步骤、找到正确结果的次数、复制差错和冲突时用户选择。找结果收益归 C004，副本复制收益归 C006；两者不合并成导出器成绩。先固定输入和测量规则，再执行。

## 2. 必需测试矩阵

| 要求/风险 | 合法例 | 拒绝或故障例 | Owner |
| --- | --- | --- | --- |
| 结果资格与版本 | 同版本 succeeded 的明确结果被导出 | 无结果、未完成、不同版本、格式不支持均不产生业务文件 | T01 写 oracle，T02 实现 |
| 实际源字节 | 引擎同句柄读取的字节与 ArtifactRef 相符 | 源被替换/截断/增长/改写，导出器 stdout 丢失或进程非零 | T01/T04 |
| 来源清晰 | manifest 保留 ArtifactRef、完整 commit、结果摘要 | 不猜最新 Attempt，不把 commit 引用当代码副本 | T01/T02 |

| 路径 | 安全相对名称可读写 | `..`、绝对路径、空段、NUL、编码碰撞和软链 | T01/T04 |

| 恢复 | 同一请求补缺失项 | 参数、结果摘要、目录身份或 request 字节不同停止 | T03/T04 |
| 清单最后 | 所有成果读回相符后发布清单 | 任意文件未通过核对不得发布完成清单 | T03/T04 |

| 无业务状态写回 | 导出前后状态/请求/审计语义一致 | 导出器没有 Store 写入口，也未调用 Work 写命令 | T03/T05 |
| 真实 CLI | 两份真实二进制、临时 Home、真实目标目录 | 假源字节成功不能替代真实子进程失败路径 | T03/T05 |
| 跨文件系统 | 不同设备间逐字节复制 | 不能靠 rename/link；测试设备不可用须标 `not_run` | T03/T05 |
| 分发 | 同 tag 的双归档独立安装后版本一致 | 缺另一归档、sha256 错误、版本不匹配拒绝 | T06/T07 |

所有边界值复用 C004 源文件限额；导出器自己的报文和生成文件上限由 T01 冻结，恰好上限/多一个拒绝都要有手写 oracle。每个拒绝例保留业务输出集合与根外哨兵逐字节及权限检查，不能只断言错误码。

## 3. 崩溃与竞态

T03 写可重复 failpoint/子进程 kill 场景：request 临时写一半、request 同步后未发布、request 已发布、成果写一半、成果已同步未发布、成果已发布未同步目录、全部成果读回前、manifest 已同步未发布、manifest 已发布。每个场景重跑同一请求，逐项比较实际字节、源摘要、已有文件 inode/权限和清单；报告进程被杀时哪些文件已持久化，不把多文件复制当事务。

竞态在目录打开后替换路径、临时文件同步后竞争创建目标、已有文件打开后替换名称、同一请求并发执行。平台判断来自当前支持平台上的真实操作。没有 macOS 机器或跨设备测试载体的场景标 `not_run`，并列出其阻断范围；Linux 静态编译不替代 macOS 写入保证。
