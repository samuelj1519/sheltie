# C008 实验规格

状态：`proposed`；实验为 `not_run`。本方案不修改当前产品合同，不向 core/runtime 写入预检结果。

## 1. 实验对象

输入取自真实 Workbook 的 manifest `requires` 和当前 Node 的 `requires[]`。当前格式已经支持 `kind`、`name`、可选 `version`、`digest` 和 `source`；Node 项通过 `<kind>:<name>` 引用声明。它们是实验必须读取的显式依据，不扩展 Workbook 字段。任务作者先按正常 Workbook 流程确认定义合法；探针只投影需要的声明，不复制完整解析/编译器，也不代办安装或装入。

实验配置位于 package 内拟新增 `experiment/probe.toml`，只记录本次使用的 Workbook/Node、宿主与版本、工作区、作者确认真正必需的资源集合和允许只读观察的路径。此配置不是新的 Workbook 合同，不安装到管理根。作者的「本次任务确实必需」是实验说明，不改写为引擎核实事实。

首批只选一个真实宿主、一个可直接观察的资源类别。优先选真实已需要的 skill；若样本依赖 MCP 或命名 subagent 而无可靠只读观测途径，保持未知或停止实验，不先建适配器平台。

## 2. 预检输出

`DR-01` **明确来源。** 每个观察携带 kind/name、Workbook 与 Node、声明的 source/version/digest、观察时间、宿主版本、工作区、检查器版本、实际观察路径与证据来源。缺少来源证据就不能说身份已匹配。

`DR-02` **逐项分开。**

| 检查项 | 能报告什么 | 不能据此推出什么 |
| --- | --- | --- |
| 存在 | 允许观察范围中发现声明对应资源，或确知不存在 | 宿主一定选它 |
| 可解析 | 按已核对宿主规则确定实际选择；无法确认则未知 | 外部网络、权限或工具可用 |
| 声明匹配 | 可直接确认的 source/version/digest 与声明一致或不符 | 可执行效果、安全性或最终使用 |
| 运行时前提 | 默认未知；只有明确、无副作用的只读检查提供事实 | 一次预检后始终可用 |

输出状态为 `matches`、`mismatch`、`unknown`。字段分别存储，不用一个总体通过位掩盖未知。缺失属于有证据的 mismatch；无法区分搜索优先级、版本条件没有可靠解释器、source 元数据不可核时均为 unknown。版本文本只作原样声明；未定义匹配语义时不得自行按字符串相等解释版本范围。

`DR-03` **摘要口径。** 只比较合同允许且实验能复现的摘要。Workbook digest 字段表示怎样的 skill 内容闭包必须由作者和阶段架构 Owner 先固定：只对 SKILL.md 算摘要不能声称整个带 scripts/resources 的 skill 匹配。无法确认闭包时摘要结果为 unknown，而不是自定摘要算法。

`DR-04` **只读提示。** 外部结果不会自动调用 `attempt begin`、`fail`、`cancel` 或替换。明确缺失/身份不符时提示协调者停止并核对；unknown 供人决定。实际调用工具失败按当前 Attempt 合同处理，本实验不把它回溯改成预检失败，不提供不消耗重试的运行时新状态。

## 3. 观察与信任

- 检查宿主选择顺序时先核对固定版本的官方资料或无副作用实际观察，保留出处、时间与版本；通用记忆中的搜索目录不是本次证据。
- 声明 source 只是数据，不执行下载、安装或联网认证；不读取凭据内容，不把 token 写入证据。
- 不执行 skill 本身、用户 hook 或自然语言指令来「证明可用」。只读观察可能无法说明可用性，准确记未知。
- 单次结果描述检查时刻。没有缓存与 TTL；再次执行就得到另一条观察，不覆盖第一次。
- 「已使用」若有宿主原生可读记录可附为事后观测；没有则未知。执行者自报另标 `reported`，不能写成 observed，也不反向修改预检。

## 4. 停止与产品化

没有明确 requires、作者确认的真实必需资源、固定宿主版本或可用只读观察时，停止该对象的执行。无样本时保留真实价值 not_run。夹具中人为制造缺失仅验证机制，不能算自然需求或避免的真实失败。

只有实际使用持续出现同类缺失/身份不符、人工核对成为主要负担、外部工具获得净收益时，才允许形成下一份采用建议。建议仍由人决定，不自动进入内核，不把未知塞成全局准入状态。需要运行才能知道的前提不能要求先确认后开始，否则会形成无解循环。

存在状态的缺失结论必须建立在完整宿主解析位置均已核实且获准观察的条件上；仅在允许范围内未找到时，输出范围内未发现证据，存在与解析仍为 unknown，不扩大文件访问权限。
