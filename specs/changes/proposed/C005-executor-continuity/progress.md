# C005 交接

状态：`proposed`；尚未采用。实现、实施里程碑审查和真实接续验证均为 `not_run`。任务状态的唯一入口是 [plan.md](plan.md)，此处不复制任务表。

采用后每次交接只更新以下字段：

| 字段 | 当前值 |
| --- | --- |
| 候选 / 工作树 | 尚无实施候选；基线见 README |
| 当前任务与 Owner | 未开始；采用时指定 |
| 已冻结接口与测试基准 | 尚未冻结 |
| 实际通过的命令 / raw run ID | 无 |
| 未完成、失败或 not_run 的验证 | 全部实施与实验验证 |
| 阻断输入或接口缺口 | 无真实替换使用证据；采用时核 C004 完成候选 |
| 下一个合法动作 | 人决定是否采用；不自行实施 proposed |

交接不能把历史请求的 next 当作当前合法操作。记录接手命令、具体原 AttemptId、是否确认旧进程停止、是否共用工作区；不得把这些人工报告写成引擎已验证的事实。
