# C005 独立方案审阅（2026-09-27）

审阅对象：本 package 的五份提案文档；对照当前 GF-05/GF-13/GF-14/GF-15、C004 共用接口与 C002 进度。本文件不改变 package 的 `proposed` 状态。人工接续、自动接续与失败路径测试均为 `not_run`。外部依据见 [一手来源笔记](../../../research/2026-09-27-agent-rust-guidance.md)。

## 结论与产品价值

**人工接续值得先做实验；自动接续暂不具备采用依据。** 在执行者或协调者被额度、会话故障打断时，从 Store 重新生成交接材料，维持原标准与已登记发现，符合 Sheltie 的状态权威定位。方案正确区分了人工、辅助、自动接续，并承认 skill 与状态卡无法在协调者停机后自行唤起备选。第一阶段可用现有 CLI 做低成本探针；第二阶段的前台驱动、额度通道和跨宿主权限政策属于另一层工程，必须由第一阶段的真实等待与重做成本触发。

宿主正在提供会话恢复、模型选择和长任务运行能力；这些会改变 C005 的增量，不能把当前宿主限制写成长期产品事实。官方材料支持保留可检查的状态与清晰交接，但没有证明「跨宿主自动切换」比使用宿主原生恢复更划算。Rust 实现若进入第一阶段，执行代次和等待应由 `core` 穷尽状态转换，`runtime` 只保证事务与恢复，不为两个宿主各造状态机。

## 采用前需修订

1. **高：定义从旧 `running` Attempt 到新执行代次的原子交接。** EX-02 说换人产生新 Attempt 并拒收旧代次，但现有协议没有「撤销运行中的 Attempt 后领取新 Attempt」操作。须规定谁能声明旧执行者中断、旧 Attempt 的终结事实、同一 Occurrence 与新 Attempt 的关系、写锁内何时递增代次，以及旧进程写文件但未提交时如何保留或隔离。真实 CLI 反例应在旧提交与新领取并发时证明至多一个被接受；恢复后从 Store 重建同一结果。仅按代次拒绝 `submit` 不能阻止旧进程继续写共享工作区，方案已承认这一点，应作为交接条件显示。
2. **高：资源不可用的来源不能混成已观测系统事实。** EX-03 允许模型自报成为等待依据，同时声明模型自报不能成为系统事实。若它直接把 Work 置为 `blocked(resource_unavailable)`，这个状态本身就是由自报触发的系统事实。应区分「未核实的中断请求」与「已确认的资源不可用」，或把模型自报触发的等待明确标成保守暂停，附来源、计数上限和恢复条件；不能显示为提供方确认的额度耗尽。模拟中断与真实提供方事件在实验中分别报告。
3. **高：第一阶段与 C004 的先后要选一条真实可交付链。** `README.md` 容许 C005 先于 C004，但 EX-01 交接包字段依赖 C004 证据、审查发现和候选快照；EX-07 的独立审查资格也依赖 C004 VD-10 的身份记录。若先做 C005，应收窄第一阶段承诺为现有状态卡、产物指针、冻结 Workbook 和执行代次，明确无法保证审查发现保留或独立性；若保留这些承诺，就把 C004 共用接口和相应任务列为前置。不可在没有来源时造一份平行发现账本。
4. **中：不要把未知额度视为可切换许可。** EX-10 对缺失观测记未知是对的；EX-11 的过滤语句只排除「已观测为耗尽」，可能把未知候选当作可用。自动尝试可以是经过授权的一次探测，但必须受资源重试、切换上限和费用边界约束，并记录它不代表额度确认。读取 `next` 后到实际启动前的资格、政策和候选集合重核应有真实驱动入口测试。
5. **中：两阶段授权与进度单独闭合。** 第一阶段实验只证明交接材料是否够用；不能验证执行代次、等待或资格门禁，`validation.md` 已承认。采用第一阶段时还需为这些机制补真实入口与故障窗口；第二阶段另设采用决定与任务计划，不要用第一阶段结果给自动驱动记 PASS。额度通道和 CLI 参数按固定宿主版本核对；未知错误保留未知。

## 推进建议与验收口径

在 C002 恢复闭合后，先用两个宿主和同一组任务做人工接续探针，分别报告同宿主恢复与跨宿主替换；记录重新解释、约束丢失、重做、人工分钟和墙钟等待。探针若显示交接缺口，先改交接包。选定与 C004 的实施顺序后，再写执行代次与等待的状态合同，并以「旧提交迟到」「驱动被杀」「无合格备选」「权限政策拒绝」「缺额度观测」做一条件反例。自动驱动仅在无人响应等待成为实测主要成本、且前台进程能够从 Store 无分叉恢复时立项。

**建议状态：第一阶段保留 proposed 并补交接机制；第二阶段继续作为候选，不随 v0.3 自动打包采用。**
