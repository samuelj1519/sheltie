# Historical task tooling maps

This directory retains historical task allowlists, completion-state rows, and original test declarations used by check-task.sh and check-tests.sh. MVP has 196 test declarations; check-tests verifies existence and ownership. Later changes use source Task comments and active plans for ownership.

Task file lists and states retain their original meaning; explanatory comments use English. Ledgers extract task states, headings, and Tests lines, without implementation bodies, review, or execution evidence. The original snapshot is `9d98bf8f15944b7bda4fbd4096e7771b09eab728`. Current implementation progress comes only from the active plan. Passing historical tools establishes neither current product capability nor the original execution environment.

See [documentation maintenance](../../docs/en/how-to/maintain-docs.md) for current content and historical lookup.
